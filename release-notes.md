## Reese The Red Dog — v0.1.2

Body-only ReSkate costume with Reese’s red texture and pale-yellow collar.

### Install
Download the mod ZIP below and install it through the ReSkate launcher or a Thunderstore-compatible mod manager. In game, select **Skaters → Apparel → Costumes → Reese Body Test**.

### Compatibility
Native patch targets **skate. build 25414733**. Tested skating with ReSkate 2.0.2; loaded in the Hub with ReSkate 2.0.7. Later game builds may need an updated package. Separate 3D fur cards are not included.

- Updated skate-shop icon.
- Three promotional mockups included; these are not gameplay screenshots or bundled maps.
